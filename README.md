# 고등학교 교육과정 자동 검토

2022 개정 교육과정 **학점 배당표(.xlsx)** 를 업로드하면 자율점검표 기반 **29개 항목**을
자동 검토해 PASS / FAIL / WARN / INFO 로 판정하는 Flask 웹앱입니다.

> ⚠️ **2022 개정 교육과정 전용**입니다. 2015 개정 배당표는 시트·열 구조가 달라 지원하지 않습니다.

## 쓰는 방법

로그인 → 배당표 `.xlsx` 업로드 → 검토 결과 확인 → 필요 시 CSV 다운로드.

- **여러 파일을 한 번에** 올리면 파일별 요약 페이지가 나옵니다(1개만 올리면 상세로 바로 이동).
  한 번에 최대 100개, 총 40MB.
- 검토 이력이 남아 다시 열거나(`/history`), **보관된 원본으로 재검토**하거나(`/recheck`),
  원본 xlsx를 다시 받을 수 있습니다.
- 로그인은 **실명 입력 방식**입니다. 처음 쓰는 이름이면 그대로 계정이 만들어집니다.
  자기가 올린 자료만 보이고, `master` 계정은 전체를 봅니다.

## 검토 항목 (29개)

| 영역 | 항목 |
|------|------|
| **A. 총량** (4) | 총 이수학점 ≥ 192 · 교과 174 · 필수이수 ≥ 84 · 창체 18 |
| **B. 학점범위** (7) | 공통과목 운영학점 · 일반선택 3~5 · 진로·융합선택 3~5 · 체육·예술·교양 2~4(특수 1~2) · 동일 과목 동일 운영학점 · 운영학점 = 학기 배치 합 · 한국사 1·2 각 3학점 |
| **C. 편성순서** (6) | 공통→선택(교과군별) · 위계 Ⅰ→Ⅱ · 체육 매 학기 · 1학년 선택과목 지양 · 종교 복수 편성 · 체육 10학점 이상 |
| **D. 균형** (3) | 학기 간 차이 ≤ 5 · 기초교과(국·수·영·한국사) ≤ 교과의 50% · 교과 174 초과분 50% 룰 |
| **E. 표기** (3) | 과목명 표기 정합성 · 교차이수 `[ ]` 표기 · 비표준 과목 비고 표기 |
| **F. 수동확인** (6) | 고시 외 과목 학점 범위 · 과목명 최종 확인 · 고시 외/교육감 승인 과목 유형 · 학기 단위 이수(완결성) · 2022 개정 과목 적용 · 기록 형식 준수 |

판정 4종을 이렇게 씁니다.

- **PASS / FAIL** — 정량 기준 자동 판정
- **WARN** — 위반일 수도 있지만 정당한 예외가 있어 사람이 봐야 하는 것.
  1학년 선택과목(C4)처럼 유동적으로 편성하는 경우, 고시 외 과목이라 저학점(1~2)이
  가능한 경우, 선택 조건 때문에 실제 이수가 상한값보다 줄 수 있는 경우(D2)가 여기 들어갑니다.
- **INFO** — 자동 판정 대상이 아니고 안내만 하는 것(F 영역, 그리고 값을 못 구한 경우)

## 실행

```bash
python -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python server.py
```

http://localhost:4001 로 접속합니다. 포트는 `PORT` 환경변수로 바꿉니다.
운영에서는 `run.sh`가 waitress로 띄우므로 PM2에 그대로 물릴 수 있습니다.

```bash
pm2 start run.sh --name curri-check
```

> ⚠️ 기본 포트가 **4001**입니다. 홈서버에 이미 4001을 쓰는 프로세스가 있는지 먼저 확인하세요
> (`~/Projects/claude-forge/reference/server-inventory.md`).

### 마스터 비밀번호

`master` 계정 비밀번호는 코드에 넣지 않습니다. 둘 중 하나로 줍니다.

- 환경변수 `CURRI_PASSWORD` (우선)
- 저장소 루트의 `.auth_password` 파일

세션 서명 키는 `.flask_secret`에 자동 생성·보관됩니다. **둘 다 커밋하지 마세요.**

## 테스트

```bash
.venv/bin/pip install -r requirements-dev.txt
.venv/bin/python -m pytest -q
```

익명화한 실제 배당표(`test/fixtures/sample_curriculum.xlsx`)로 과거에 결과가 틀렸던
지점을 고정합니다. **`parser.py`나 `checker.py`를 고치면 반드시 돌리세요** — 파싱이
한 칸 밀리면 29개 규칙 판정이 전부 어긋납니다(실제로 첫 과목이 통째로 누락된 적이 있습니다).

## 구조

| 파일 | 역할 |
|------|------|
| `server.py` | Flask 라우팅 + waitress 진입점. 로그인·업로드·검토·이력·재검토·CSV |
| `templates/` | 화면 8개. `batch.html`은 별도 URL이 아니라 `/check`가 여러 파일일 때 렌더 |
| `parser.py` | 엑셀 파싱. 시트·데이터범위 자동 탐지, 병합셀 forward-fill, 과목명 NFC 정규화, 과목유형 약어 표준화 |
| `checker.py` | 29개 검토 단위 판정 |
| `db.py` | SQLite. 검토 이력·사용자·원본 보관 |
| `test/` | pytest 회귀 테스트 + 익명화 fixture |

## 고칠 때 알아둘 것

- **과목명은 NFC로만 정규화합니다**(`_norm_name`). NFKC는 로마숫자 Ⅰ/Ⅱ를 영문 I/II로
  바꿔 표기 검사(E1)와 위계 검사(C2)를 망가뜨립니다.
- **데이터 시작 행을 고정 오프셋으로 잡지 마세요.** 헤더 높이·spacer 행이 학교마다 다릅니다.
  `find_data_range`는 '과목명이 있고 학점이 숫자인 첫 행'을 스캔합니다.
- 규칙 추가는 `checker.py`에서 `add(id, 영역, 항목, 기준, 측정값, 판정, 근거)` 형태로 넣습니다.
  선택과목 학점범위처럼 "하한 미달은 WARN, 그 외 위반은 FAIL"인 패턴은 `add_sel_range`를 씁니다.
- 기준값을 상수로 박기 전에 계산식으로 쓸 수 있는지 보세요. D2의 한도가 오래 `81`로
  박혀 있었는데, 이는 `174×50% − 한국사 6`이라 '교과총 174·한국사 6'이 숨은 가정이었습니다.
